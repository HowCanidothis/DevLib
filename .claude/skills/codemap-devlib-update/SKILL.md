# codemap-devlib-update — обновить все индексы и карту DevLib

Ты — исполнитель. Ты запускаешь скрипт и субагентов Opus. Ты НЕ анализируешь код, НЕ читаешь индексы и НЕ пишешь CODEMAP.md сам.

Обновляются только уже проиндексированные папки (список хранится в `codemap.folders`, он лежит в git). Новые папки — через `/codemap-devlib ПАПКА`.

## Где лежит проект

DevLib — папка с `codemap.py` в корне, по умолчанию `D:\Work\wps-client\libs\DevLib`. Код лежит на компьютере пользователя, не в облачном контейнере. В Cowork подключённая папка видна как `$HOME/mnt/ИМЯ_ПАПКИ`; все команды — через `mcp__remote-devices__device_bash` с префиксом `cd "$HOME/mnt/DevLib" && ` (если папка называется иначе — подставь её имя), Python — `python3`. Без инструментов `mcp__remote-devices__*` — терминал из папки DevLib (`python`/`py`).

## Шаг 0. Доступ и скрипт

1. `ls "$HOME/mnt/"`. Есть папка с `codemap.py` (обычно `DevLib`) — дальше. Нет — ОДИН раз `mcp__remote-devices__device_request_folder_access` с `paths: ["D:\\Work\\wps-client\\libs\\DevLib"]`, причина «Обновление карты кода». Если такой папки на этой машине нет — СПРОСИ у пользователя путь к DevLib и запроси доступ к нему. Отказ — остановись. Доступ — ТОЛЬКО к DevLib, не к wps-client.
2. `cd "$HOME/mnt/DevLib" && ls codemap.py` — нет: ОСТАНОВИСЬ и скажи об этом.

## Шаг 1. Состояние

```
cd "$HOME/mnt/DevLib" && python3 codemap.py status
```

Каждая строка — одна папка (свежесть определяется по хешу содержимого, не по датам файлов, поэтому `git pull` и другая машина на неё не влияют):

- `OK` — индекс свежий;
- `NOINDEX` — индекса нет (свежий клон, `.codemap/` не в git);
- `OLD` — индекс построен другой версией скрипта;
- `CHANGED` — исходники папки изменились с прошлой индексации;
- `MISSING` — папки больше нет (только упомянуть в отчёте);
- `section=1` — у папки есть раздел в CODEMAP.md; `section=0` — папка проиндексирована только как зависимость.

План:

- **Индексы** перестраиваются для всех `NOINDEX`, `OLD`, `CHANGED` — это бесплатно (без ИИ), подтверждение не нужно.
- **Разделы карты** (каждый — отдельный запуск Opus, это дорого) — только для папок `CHANGED` с `section=1`: только у них код реально разошёлся с картой. `NOINDEX` и `OLD` раздел не требуют: карта пришла из git и соответствует коду.
- Если пользователь сказал «только индексы» — разделы не трогать вообще. Если сказал «принудительно» / «всё заново» — индексы `reindex --all`, разделы — все с `section=1`.

Покажи пользователю план. Если в нём есть запуски Opus — СПРОСИ подтверждение на них (индексы можно делать сразу). Всё `OK` — скажи «Всё актуально» и остановись.

## Шаг 2. Переиндексировать (бесплатно)

```
cd "$HOME/mnt/DevLib" && python3 codemap.py reindex
```

(`reindex --all` — если «принудительно».) Скрипт печатает `REINDEX DONE` и списки переиндексированных и актуальных папок. Нет `REINDEX DONE` — покажи последние 20 строк вывода и остановись. Скрипт не чини.

Режим «только индексы» или в плане нет запусков Opus — переходи к шагу 4.

## Шаг 3. Обновить разделы карты

Загрузи скилл `codemap-devlib` (инструмент Skill) и возьми из его шага 4 промпт для Opus — дословно.

Для каждой папки из подтверждённого списка, ПО ОДНОЙ ЗА РАЗ: запусти субагента `model: opus` с этим промптом, подставив ПАПКА и КАТАЛОГ_ИНДЕКСА (`.codemap/ИМЯ_ЧЕРЕЗ__`). Перед текстом промпта добавь строку: «Это плановое обновление: раздел «## ПАПКА» уже есть, перепиши его по свежему индексу».

Ответы субагента обрабатывай как в шагах 5а и 5б скилла `codemap-devlib`:

- `NEED_FILES:` — `python3 codemap.py dump ...` и SendMessage тому же субагенту;
- `NEED_INDEX:` — СПРОСИ пользователя; согласился — `python3 codemap.py index ПАПКА` и SendMessage; отказался — SendMessage «Индекса не будет, закончи раздел с пометками (?)».

Если инструмента Agent нет — напиши пользователю, для каких папок нужно обновить разделы, и остановись.

## Шаг 4. Отчёт

Коротко: переиндексированы …; разделы обновлены … (строки «Замечания: открыто N, закрыто M»); актуальны …; папки, которых больше нет …; ошибки …. Без пересказа содержимого.

## Запрещено

- запрашивать доступ к чему-либо кроме папки DevLib;
- индексировать новые папки (кроме NEED_INDEX с согласия пользователя);
- создавать разделы карты для папок с `section=0`;
- запускать Opus для папок `NOINDEX`/`OLD` (кроме режима «принудительно») и несколько Opus параллельно;
- читать исходники или файлы `.codemap/` и делать по ним выводы;
- менять codemap.py, код проекта или CODEMAP.md самому;
- удалять что-либо.
