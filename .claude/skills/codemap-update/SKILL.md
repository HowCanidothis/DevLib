# codemap-update — обновить индексы и карты

Ты — исполнитель. Запускаешь скрипт и субагентов Opus. Код, индексы и карты сам НЕ читаешь и НЕ пишешь.

Обновляются только уже проиндексированные папки (`codemap.folders` каждого проекта). Новые — через `/codemap ПАПКА`.

## Шаг 0. Корень

Как в скилле `codemap` (шаг 0): `ls "$HOME/mnt/"` → КОРЕНЬ = `$HOME/mnt/wps-client`, или `$HOME/mnt/DevLib`, если подключена только DevLib; иначе ОДИН раз запроси доступ к `D:\Work\wps-client` (нет такой папки — спроси путь; отказ — остановись). Команды — `mcp__remote-devices__device_bash` с префиксом `cd "КОРЕНЬ" && `, `python3`. Без Cowork — терминал в корне (`python`/`py`).

Если в КОРНЕ нет `codemap.py`, а есть `libs/DevLib/codemap.py` — корневая карта на этой машине не настроена. Тогда работай из `libs/DevLib`: все команды ниже — с префиксом `cd "КОРЕНЬ/libs/DevLib" && `, а сабмодули WPSModule и RModule обнови отдельно тем же способом (`cd "КОРЕНЬ/libs/WPSModule" && python3 ../DevLib/codemap.py sync && python3 codemap.py ...`). Предложи пользователю настроить корень (`/codemap` → «Настройка корня»), но без согласия не настраивай.

## Шаг 1. Состояние

```
python3 codemap.py sync && python3 codemap.py status
```

`sync` копирует актуальный `codemap.py` из DevLib в корень и сабмодули. `status` — по строке на папку, со всеми связанными картами (свежесть — по хешу содержимого, не по датам, поэтому `git pull` и другая машина не мешают):

- `OK` — свежий; `NOINDEX` — индекса нет (свежий клон: `.codemap/` не в git); `OLD` — другой версией скрипта; `CHANGED` — код папки изменился; `MISSING` — папки больше нет (только упомянуть);
- `section=1` — у папки есть раздел в карте; `section=0` — только индекс;
- префикс `[DevLib]` и т.п. — папка из карты сабмодуля; путь в строке уже от корня;
- `WARNING: ... codemap.py differs` — повтори `sync`.

План:
- **Индексы** — все `NOINDEX`, `OLD`, `CHANGED`. Бесплатно (без ИИ), подтверждение не нужно.
- **Разделы карт** (каждый — отдельный запуск Opus, дорого) — только `CHANGED` с `section=1`: только там код разошёлся с картой. `NOINDEX`/`OLD` разделы не трогают: карта пришла из git вместе с кодом.
- «только индексы» — разделы не трогать вообще. «принудительно» / «всё заново» — `reindex --all` и разделы всех папок с `section=1`.

Покажи план. Если в нём есть запуски Opus — СПРОСИ подтверждение на них (индексы делай сразу). Всё `OK` — «Всё актуально», стоп.

## Шаг 2. Индексы

`python3 codemap.py reindex` (или `reindex --all`). Если нет файла `.codemap/_extern.tsv` или пользователь сказал «принудительно» — ещё `python3 codemap.py extern` (список классов сторонних библиотек для `find`, около минуты). Обе команды — `device_bash` с `timeout_ms: 180000`. Ждёшь `REINDEX DONE` и строки `reindexed:` / `up to date:` по каждому проекту. Нет `REINDEX DONE` — покажи последние 20 строк и остановись. Скрипт не чини.

«только индексы» или нет запусков Opus — к шагу 4.

## Шаг 3. Разделы

Загрузи скилл `codemap` (инструмент Skill) и возьми промпт для Opus из его шага 4 — дословно. Для каждой подтверждённой папки ПО ОДНОЙ: субагент `model: opus` с этим промптом; ПАПКА — путь из `status` (от корня), КАТАЛОГ_ИНДЕКСА — `.codemap/ИМЯ` её проекта (например `libs/DevLib/.codemap/PropertiesModule`, `libs/WPSModule/.codemap/_root`, `.codemap/WPSClient`; при сомнении — `python3 codemap.py index ПАПКА` напечатает пути). Перед промптом строка: «Плановое обновление: раздел папки ПАПКА уже есть, перепиши его по свежему индексу».

Ответы: `NEED_FILES:` → `python3 codemap.py dump ...` и SendMessage; `NEED_INDEX:` → СПРОСИ пользователя; да — `python3 codemap.py index ...` и SendMessage, нет — SendMessage «Индекса не будет, закончи раздел с пометками (?)».

Без Agent — перечисли пользователю папки, чьи разделы надо обновить, и остановись.

## Шаг 4. Отчёт

Коротко: переиндексированы …; разделы обновлены … (строки «Замечания: открыто N, закрыто M»); актуальны …; пропавшие папки …; ошибки …. Что коммитить: в сабмодулях — изменённые `CODEMAP.md`, `codemap.folders`, `codemap.py`; карта корня wps-client локальная.

## Запрещено

- запрашивать доступ к чему-либо кроме wps-client (или DevLib);
- индексировать новые папки (кроме NEED_INDEX с согласия);
- создавать разделы для `section=0`; запускать Opus для `NOINDEX`/`OLD` (кроме «принудительно») и несколько Opus параллельно;
- читать исходники или `.codemap/`; менять codemap.py, код или карты самому; удалять что-либо.
